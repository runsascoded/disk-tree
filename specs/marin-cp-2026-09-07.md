## `packages/react/src/TimeSeries.tsx` — `onBrush` + `window` (gcs `f30230c`)

Additive, default-off, same shape as the 9/4 props:

- `onBrush?: (x0, x1) => void` — drag across the plot picks an x-range, both ends snapped to data x's; the release is committed from a `window` `mouseup` listener (`{ once: true }`) so a drag that ends past the plot edge still lands, and a zero-width drag falls through to `onPickX`. With a brush, the SVG's `onClick` is dropped (the pick resolves in mouseup) so a click never fires twice. The in-progress drag lives in a ref (state flushes in a microtask under `createRoot`; down/move/up in quick succession would read stale closures) with a state copy for rendering.
- `window?: [number, number]` — a shaded band behind the series (`--dt-ts-window`, edges `--dt-ts-window-edge`, dashed); a drag in progress draws the same band solid (`--dt-ts-brush`). Cursor: `col-resize` while dragging, `crosshair` with a brush, `pointer` with only `onPickX`.
- `userSelect: 'none'` on the SVG, `preventDefault` on mousedown.

Take it from `m/gcs:packages/react/src/TimeSeries.tsx` (only the `@rdub/treemap` vs `./colors` import differs — gcs is still pre-extraction).
